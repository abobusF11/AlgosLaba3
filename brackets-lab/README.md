# Brackets Lab

Консольная программа на Go для проверки корректности скобочной последовательности.

Программа проверяет пары скобок:

- `()`
- `[]`
- `{}`
- `<>`

Также программа умеет игнорировать обычные символы, поэтому можно проверять не только строки из скобок, но и выражения вида:

```text
if (a[2] > b) { return true }
```

## Что делает программа

Для каждой введённой строки программа выводит:

- корректная скобочная последовательность или нет;
- позицию ошибки, если строка некорректная;
- причину ошибки;
- количество корректно закрытых пар скобок;
- максимальную глубину вложенности;
- количество открывающих и закрывающих скобок.

## Используемый алгоритм

Проверка реализована через стек.

Алгоритм:

1. Если встретилась открывающая скобка, она добавляется в стек.
2. Если встретилась закрывающая скобка, программа проверяет последнюю открытую скобку в стеке.
3. Если скобки совпадают, последняя открытая скобка удаляется из стека.
4. Если скобки не совпадают, программа возвращает ошибку.
5. После прохода по строке стек должен быть пустым.
6. Если стек не пустой, значит в строке есть незакрытая скобка.

## Архитектура проекта

Проект сделан в упрощённом стиле Clean Architecture.

```text
brackets-lab/
├── cmd/
│   └── app/
│       └── main.go
├── internal/
│   ├── domain/
│   │   └── brackets.go
│   ├── usecase/
│   │   ├── validator.go
│   │   └── validator_test.go
│   └── delivery/
│       └── cli/
│           └── handler.go
├── .gitignore
├── go.mod
└── README.md
```

### `cmd/app`

Точка входа в приложение.

Файл `main.go` создаёт валидатор, создаёт CLI-handler и запускает программу.

### `internal/domain`

Слой с базовыми структурами предметной области.

Здесь лежат:

- `BracketPair` — пара скобок;
- `ValidationResult` — результат проверки строки.

### `internal/usecase`

Слой с основной логикой приложения.

Здесь находится `Validator`, который проверяет строку через стек.

### `internal/delivery/cli`

Слой для работы с консолью.

Он отвечает только за ввод и вывод:

- читает строку из терминала;
- передаёт строку в валидатор;
- печатает результат проверки.

## Требования

Нужен установленный Go версии 1.22 или выше.

Проверить установленную версию можно командой:

```bash
go version
```

## Как запустить

Перейдите в папку проекта:

```bash
cd brackets-lab
```

Запустите программу:

```bash
go run ./cmd/app
```

После запуска появится приглашение для ввода:

```text
Введите строки для проверки.
Пустая строка завершает ввод.

>
```

Введите строку, например:

```text
([]{})
```

Пример результата:

```text
"([]{})" -> true
Пар: 3, глубина: 2, открывающих: 3, закрывающих: 3
```

Чтобы завершить программу, нажмите `Enter` на пустой строке.

## Как собрать исполняемый файл

```bash
go build -o brackets ./cmd/app
```

Запуск на Linux/macOS:

```bash
./brackets
```

Запуск на Windows:

```bash
brackets.exe
```

## Примеры строк для проверки

```text
()
([])
{[]}
<([])>
([)]
a + (b * c)
if (a[2] > b) { return true }
(()
())
```

```text
"()" -> true
Пар: 1, глубина: 1, открывающих: 1, закрывающих: 1

"([])" -> true

Пар: 0, глубина: 2, открывающих: 2, закрывающих: 1
```

## Краткое описание для защиты

В этой работе реализована проверка скобочной последовательности на языке Go. Алгоритм основан на стеке: открывающие скобки помещаются в стек, а при встрече закрывающей скобки проверяется последняя открытая скобка. Если типы скобок не совпадают или стек пустой, строка считается некорректной. После обработки всей строки стек должен быть пустым.

Код разделён по упрощённой Clean Architecture: `domain` содержит структуры данных, `usecase` содержит алгоритм проверки, `delivery/cli` отвечает за консольный ввод и вывод, а `cmd/app` запускает приложение.
